# ScanMaster 智能文档扫描工具

一个本地离线的桌面文档处理工具，类似"夸克扫描王"的核心能力：拖拽导入图片/PDF，自动扫描矫正、提取文字、转换成 Office 文档。**全部识别在本地完成，不上传任何数据。**

## 功能

- **文档扫描矫正** — 自动检测纸张边缘、透视变换拉正，**保留整张纸（含页眉页脚，A4 比例）**，去阴影 + 形态学去噪，输出干净白底黑字扫描件（夸克扫描王式效果）
- **手工调整裁剪** — 自动截取不完整时，在预览窗口点「手工调整裁剪」，在原图上拖动四角重新框选纸张，可锁定 A4 比例 / 复位，调整后实时刷新预览，确认才导出
- **提取文字** — 本地 OCR 识别，表格按行列顺序排列，导出 TXT
- **图片转 Word** — 原扫描图 + 识别文字生成 `.docx`
- **PDF 转 Word** — 逐页渲染并 OCR，汇总为一个 Word 文档
- **表格转 Excel** — 基于表格线检测划分单元格，**逐单元格识别**（识别模式 + 多预处理投票，数字/代码更准），自动补齐漏检边框防列错位，还原合并单元格，导出 `.xlsx`
- **先预览再导出 · 可校对** — 所有功能执行后先弹出预览窗口，可查看扫描图与识别结果；**识别出的文字/表格可直接双击修改**（未识别出的格子标黄提示补录，支持增删行列），确认后按修改后的内容导出，取消则不产生任何文件
- **多种导入方式** — 文件拖拽、剪贴板粘贴、文件选择对话框
- **文件移出** — 导错的文件可从待处理列表移出（按钮 / 右键菜单 / Delete 键，支持多选与清空），仅移出列表不删除磁盘文件

## 安装与运行

```bash
# 1. 安装依赖（Python 3.10+，推荐 3.11/3.12）
pip install -r requirements.txt

# 2. 启动
python main.py
```

> 说明：Python 3.13 下 PaddlePaddle 支持不佳，本项目采用 **RapidOCR**（PaddleOCR 模型的 ONNX 离线移植版），无需 `paddlepaddle`，识别效果一致且兼容性更好。

## 打包为 exe

```bash
python build_exe.py
# 产物：dist/ScanMaster/ScanMaster.exe
```

## 使用方法

1. 打开软件后，把图片/PDF **拖进窗口**，或点击「导入文件」/「粘贴剪贴板」
2. 在右侧查看文件预览与列表
3. 点击底部功能按钮执行对应操作
4. 处理结果自动保存到输出目录（默认 `桌面/ScanMaster_Output`），并自动打开

## 已知限制

- **手写体识别**：底层 RapidOCR 以印刷体为主，潦草的手写中文/字母识别率有限（数字和规整字体准确率高）。表格结构（行列、单元格）能准确还原，但手写内容的字形识别可能有误差。**建议在预览窗口对照扫描图校对后再导出**——识别文字和表格均可直接编辑，未识别格子以黄色高亮提示补录。
- **复杂表格**：合并单元格通过首列向下填充还原，多层嵌套表头的复杂表格可能需要人工微调（可用预览里的「增加行/列」按钮补格）。
- **识别速度**：逐单元格识别会对每个非空格子做多预处理 OCR，格子较多的表格识别耗时较长（约十几秒），属正常现象。
- **PDF 转 Word**：按页面文字流输出，不保留原 PDF 的复杂版式。
